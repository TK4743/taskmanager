## 1. 📌 Problem Statement
Academic workflow management, student coding competency tracking, and recruitment readiness assessments in higher education institutions remain critically fragmented. Submissions are lost across unverified Google Forms and paper logbooks, faculty lack visibility into daily LeetCode/GitHub problem-solving velocity, manual evaluation delays feedback, and corporate recruiters receive untracked, unverified student claims.

---

## 2. 🔍 Existing Solutions & Critical Gaps
Conventional LMS software (Moodle, Google Classroom, Canvas) and manual spreadsheets cannot execute student code in isolated sandboxes, have zero API integration with competitive programming profiles (LeetCode GraphQL / GitHub REST), lack 3-tier hierarchical verification pipelines, and provide no empirical proctoring or automated candidate dossiers for campus recruiters.

---

## 3. 💡 Proposed Solution
VSBEC IT Vault is an institutional governance and placement readiness ecosystem adopted by 365+ enrolled students across 6 departmental sections (II IT & III IT) at VSB Engineering College. It provides a 3-tier proof verification pipeline (Peer Review → Faculty Sign-off → HOD Oversight) with Cloudinary image proof compression, automated daily LeetCode and GitHub momentum tracking daemons, an isolated Monaco IDE assessment compiler (C, C++, Java 17, Python 3) with anti-cheat webcam PIP proctoring, Telegram Bot webhook alerts, and an algorithmic Placement Readiness Index (0–100%).

---

## 4. ⚙️ Technical Approach & System Architecture
* **Frontend:** React 19, TypeScript 5.8, Vite 6, Tailwind CSS v4, Monaco Editor core with custom theme integration.
* **Backend:** Node.js 20+, Express 4.x, PostgreSQL 14+ with 35 relational tables, row-level access control, and an in-memory pre-indexed RAM cache delivering sub-0.01ms directory lookups.
* **Compiler Sandbox:** Isolated execution runtime with 4–6s execution bounds, memory limits, and infinite loop traps for C, C++, Java 17, and Python 3.
* **Integrations:** LeetCode GraphQL API, GitHub REST API, Telegram Bot API (Webhooks & Poller), 3-node Brevo email failover pool, and VAPID Web Push.
