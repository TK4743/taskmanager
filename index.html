About IT Vault VSB (VSBEC IT Task Manager)

IT Vault (VSBEC IT Task Manager) is the official student task management, submission, verification, and placement readiness platform designed for the Information Technology department of VSB Engineering College (VSBEC, Karur, vsbkarur). The platform empowers VSBEC IT (vsbecit) students, coordinators, class advisors, and department leadership (HOD) with real-time academic task workflows, LeetCode and GitHub coding velocity analytics, automated announcements, and departmental governance.

Core Features & Modules

Student Task Management

Students can view academic assignments, filter by category (Competition, Course, Workshop, College Work), and track deadlines in real time.

Task Submission & Verification Workflow

Multi-tier verification workflow supporting individual and team submissions, screenshot proof uploads via Cloud CDN, and feedback with resubmission support.

LeetCode Progress Tracking

Real-time LeetCode problem solve velocity tracking, Easy/Medium/Hard breakdown, dynamic target setting, and automated streak monitoring.

GitHub Progress Tracking

Synchronized tracking of daily and weekly student GitHub commits with combined coding performance analytics.

Corporate & Industry Placement Studio

Sandboxed multi-compiler coding qualification assessments, placement readiness scorecards, and corporate partner recruitment access.

Telegram & Email Notifications

Automated Telegram Bot alerts (@IT_TaskManager_Alerts_bot), Web Push notifications, and multi-node institutional email dispatches.

Frequently Asked Questions (IT Vault VSB)

What is IT Vault VSB?

IT Vault (VSBEC IT Task Manager) is the official academic task governance, coding progress tracking, and placement portal for the Department of Information Technology at VSB Engineering College, Karur (VSBEC / VSB Karur).

How do VSB students log in to IT Vault?

Students and faculty members log in using their official college Email ID or Register Number and password at https://it-taskmanager.vercel.app/.
